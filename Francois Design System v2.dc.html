Extracted from the redesigned shell. The rule that generates everything else: sans carries the interface, mono carries facts — paths, counts, keys, code and elapsed time. Depth comes from three stacked surfaces plus a hairline, never from heavy shadow except on things that float. One acid for action, four desaturated status hues, and a separate tinted family reserved for account identity.
